# Contributing to Awesome Marketing Mix Modeling

First off, thank you for considering contributing to **Awesome Marketing Mix Modeling**. We appreciate your time and effort in helping us build a rigorous, practical, and privacy-durable measurement resource for the marketing science community.

The goal of this project is to curate a high-quality list of open-source MMM frameworks, geo-lift and incrementality testing tools, causal inference libraries, foundational research, and public datasets. To maintain the quality of this list, please review the guidelines below before submitting a pull request.

By participating in this project you agree to abide by our [Code of Conduct](https://github.com/adops-tool/awesome-marketing-mix-modeling/blob/main/CODE_OF_CONDUCT.md).

## Submission Guidelines

Please ensure your submission adheres to the following core criteria:

- **Relevance:** The resource must be directly useful for marketing mix modeling, incrementality testing, causal inference in marketing, or reproducible MMM research and datasets.
- **Open & Accessible:** We prioritize open-source software, peer-reviewed or preprint research, public datasets, and genuinely reproducible tutorials. Closed-source SaaS pitches and paywalled vendor collateral will not be merged.
- **Active or Foundational:** We accept actively maintained projects as well as canonical foundational papers/archived reference implementations that remain instructive.
- **Direct Links Only:** Absolutely no affiliate, tracking, or referral links are allowed.

## Description Standards

Descriptions must be concise, objective, and purely informational.

- **Do:** Focus on the exact utility, methodology, and ecosystem (e.g., Python, R, JAX, Stan) of the resource.
  > *Example: "Meta's R package for end-to-end geo experiments using augmented synthetic control, with data-driven market selection, power simulations, and lift estimation."*
- **Don't:** Use marketing fluff, superlatives, or subjective claims.
  > *Example: "The world's best MMM platform that revolutionizes your marketing ROI."*

## Step-by-Step Submission Process

To add a new resource to the list, please follow these steps:

1. **Star the repository:** Show your support and help the community grow.
2. **Locate the file:** Navigate to the `README.md` file in the `main` branch of this repository.
3. **Edit the document:** Click the "Edit" (pencil) icon to begin making your changes.
4. **Format your entry:** Add your link to the appropriate category using the exact Markdown syntax below. Use the `github` icon (`image/alg_R.png`) when the primary link is a GitHub repository and the `web` icon (`image/alg_I.png`) otherwise. Always link directly to the tool's site or repository — never through search engines or redirect services:

   ```markdown
   ![github](image/alg_R.png) [Tool Name](https://github.com/org/repo) - Short, objective description of what it does.

   ![web](image/alg_I.png) [Tool Name](https://example.com) - Short, objective description of what it does.
   ```

   Do not include pricing or promotional claims in descriptions.
5. **Avoid duplicates:** Search `README.md` before adding a new entry to make sure it is not already listed.
6. **Create a Pull Request:** Submit your PR with a clear and descriptive title using the following format: `Add [Tool Name]`.
